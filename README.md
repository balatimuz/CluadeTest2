# Simple Calculator App

A clean, dependency-free calculator built with plain HTML, CSS, and JavaScript in a single file.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Percent, sign toggle (+/−), and decimal input
- Chained operations (e.g. `2 + 3 × 4` evaluated left to right as you go)
- Division-by-zero and overflow handling (shows `Error` / exponential notation)
- Full keyboard support: digits, `+ - * /`, `Enter`/`=`, `.`, `%`, `Backspace`, `Esc` (clear)
- Responsive design with automatic light/dark theme

## Usage

Open `index.html` in any modern browser — no build step or server required.

```bash
# or serve it locally
python3 -m http.server 8000
# then visit http://localhost:8000
```
